# Практична робота 3: Hello World в Flutter
**Варіант 1: Візитівка розробника**

## Опис
Застосунок візитка розробника з одним екраном. Містить аватар, ім'я, спеціальність та список контактів. Реалізовано перемикач світлої та темної тем, стан якого зберігається у `StatefulWidget`. Компонент контакту винесено в окремий файл (`contact_card.dart`).

## Труднощі та їх розв'язання
Головною складністю було правильно налаштувати передачу стану теми від батьківського `StatefulWidget` до дочірнього екрана. Це вирішено передачею колбеку `onToggleTheme` через конструктор `BusinessCardScreen`.

## Звіт про Hot Reload / Hot Restart
- **Hot Reload:** Миттєво застосовує зміни в UI без втрати стану. Якщо тема була перемкнута на темну, вона залишається темною після збереження файлу.
- **Hot Restart:** Повністю скидає стан застосунку. Після його виконання змінна `_isDarkMode` повертається до початкового значення `false`, і тема знову стає світлою.
